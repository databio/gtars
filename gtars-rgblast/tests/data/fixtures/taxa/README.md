# `taxa` fixture

Generated by `make_taxa.py` (deterministic). `tests/common/store.rs` (`build_taxa_store`) builds
it into a temporary store for each storage mode: one collection per FASTA (no alias at import),
then the aliases in `aliases.tsv` in file order, the FHR sidecars in `fhr/<collection>.json`,
and `orphan.fa` ingested with no collection.

| Collection | FHR taxon | Rows | Purpose |
|---|---|---|---|
| `human_a` | 9606 *Homo sapiens* (identifiers.org URI), `accessionID` `GCF_TEST.1` | `chr1`, `chr2`, `chr3`, `chrM` | assembly from FHR; `ucsc:hg_test` ranks after `name` |
| `human_b` | 9606 (OBO `NCBITaxon_9606` URI) | `chr1`, `chrM` (= human_a), `decoy`, `chr2b` | `insdc:GCA_TEST.1` ranks after `name` (db_tag `human_b`); assembly from the insdc alias |
| `human_masked` | 9606 (`taxonomy:9606`, padded name) | `chr1` with 198 of 300 bp N (3-bit), `chr2` (= human_a) | N fraction 0.341: `--exclude-masked` drops it |
| `mouse_a` | 10090 *Mus musculus* | `chr1` (different), `decoy` (= human_b), `7` (all-digit name), `chrUn_iupac` (4-bit) | the shared decoy has a mixed-taxon `SQ.` defline; assembly from `refseq:GCF_000002.1` |
| `nofhr` | none | `u1` | taxid 0, no species |

Other cases: `dup` is a collection alias in `ucsc` (human_a) and `refseq` (mouse_a), so the bare
selector `dup` is ambiguous and `ucsc:dup` / `refseq:dup` resolve; `refseq:NC_TEST1.1` is a
sequence alias of `chr1`; `o1` (`orphan.fa`) is in no collection.
